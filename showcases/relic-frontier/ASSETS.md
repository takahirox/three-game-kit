# Relic Frontier asset provenance and intake

## Current asset lock

Relic Frontier contains **no third-party binary assets**. The only binary files are three repository-original glTF assets: the animated Relic Ranger rig generated for the melee slice and the two hand-authored CHROMA STRIKE models, all locked below. All other visual content is self-created in repository TypeScript from Three.js primitives, materials, deterministic point data, lighting, and public three-game-kit VFX. The HUD is authored in local HTML/CSS and uses system fonts. This avoids redistribution ambiguity while keeping the slice cohesive.

## Relic Ranger rig intake record

The character-asset path that Issue #29 asked to exercise is recorded end to end:

| Step | Record |
| --- | --- |
| Source | `scripts/lib/relic-ranger-rig.mjs`: a 17-bone humanoid (`Hips`→`Spine`→`Chest`→`Neck`→`Head`, two arms with `UpperArm`/`ForeArm`/`Hand`, two legs with `Thigh`/`Shin`/`Foot`), 22 rigid box segments skinned 100 % to one bone each, vertex colours, and a blade parented to `HandR`. Facing +Z, feet on y = 0, 1.99 m tall. |
| Provenance / license | Repository-original, repository license. The GLB root node carries `extras.generator = "relic-ranger-rig v1"`. |
| Animation clips | `idle` 2.0 s, `walk` 1.0 s, `run` 0.6 s, `attack-light` 0.45 s, `attack-light-2` 0.45 s, `attack-heavy` 0.85 s, `dodge-roll` 0.55 s, `hit-react` 0.3 s, `stagger` 0.65 s, `death` 1.2 s, `cast` 0.8 s. | Preprocessing | None beyond generation: `node scripts/build-relic-ranger.mjs` exports the GLB with the Three.js `GLTFExporter` (`binary`, `trs`). Output is byte-deterministic; the intake gate regenerates it in memory and byte-compares. |
| Size | 150876 bytes (budget 512 KiB). 528 vertices, 264 triangles, 1 mesh, 1 material, 0 textures, 1 skin, 17 joints, 11 clips, 19 nodes. |
| Runtime loading | Manifest entry `relic-ranger` (`kind: "gltf"`, group `boot`) on the public `createAssetManager` with `createThreeAssetBackend`; the deterministic `failure-probe` entry remains in the same manifest so failure evidence stays covered. |

## Repeatable intake gate

Run `node scripts/verify-relic-frontier-assets.mjs`. It recursively inventories common model, image, audio, font, and compressed-texture extensions and allows exactly the three locked files above. For the CHROMA STRIKE files it checks the glTF 2.0 declaration, the shared authored generator tag, node/mesh/material counts, a single fully embedded base64 buffer whose decoded bytes match the declared byteLength, and documentation in `chroma-strike/assets/MODELS.md`. For the rig it checks the exact byte size recorded here, the 512 KiB budget, a byte-identical regeneration from `scripts/lib/relic-ranger-rig.mjs`, GLB container version 2, node/mesh/material/skin/joint counts, bone and clip names, the absence of images and textures, the embedded binary buffer, and the repository generator tag. Any other binary asset, and any missing or drifted locked file, deliberately fails the gate until this document records source, license, sizes, counts, intended runtime use, modifications, and visual verification.

Future external candidates should prefer CC0 KayKit/Kenney families, keep a single visual family, remove unused files/clips, preserve atlases, resize textures only after comparison, and use glTF optimization/compression only after the public Asset Manager supports the chosen decoding path. Before/after measurements must be committed; marketing labels such as “low poly” are not measurements.
